## 一、 基础建表与默认值 (CREATE TABLE & DEFAULT)

在创建数据表时，除了定义列名和数据类型，我们还可以使用 `DEFAULT` 关键字为字段设置默认值。

**📝 案例代码 (例 3-7)：**
```sql
CREATE TABLE S ( 
    SNo CHAR(6), 
    SN VARCHAR(10), 
    Sex NCHAR(1) DEFAULT '男', -- 缺省值为“男”
    Age INT, 
    Dept NVARCHAR(20)
);
